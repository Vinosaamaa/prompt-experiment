# Experiment prompts

This folder stores the **original experiment prompts** used to build each project in this repo.

## Convention

For every new experiment prompt the human gives:

1. Save it here as `prompts/<experiment-folder-name>.md`
2. Include title, date (if known), target folder, and the full prompt text
3. Do this on the same feature branch as the experiment (or a follow-up PR)
